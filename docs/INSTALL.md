# Установка готового JAR

Realistic Home Decor **0.2.0** предназначен для **Minecraft Java Edition 1.21.11**,
**Fabric Loader 0.20.1** и **Fabric API 0.141.6+1.21.11**. Нужна Java 21.

## Обычный Minecraft и сборки модов

1. Выберите экземпляр Minecraft 1.21.11 с Fabric в своём лаунчере.
2. Откройте папку этого экземпляра и его каталог `mods`.
3. Поместите туда **`realistic-home-decor-0.2.0.jar`** и Fabric API для 1.21.11.
   Если Fabric API уже установлен подходящей версии, второй экземпляр не нужен.
4. Удалите предыдущий JAR Realistic Home Decor из этой папки, затем запустите игру.
5. В творческом инвентаре откройте «Строительные материалы»: там находятся
   40 типов новых стен в восьми палитрах. Мебель находится в остальных вкладках.

Мод устанавливается рядом с другими Fabric-модами той же версии Minecraft.
Для работы этого JAR не нужны Python, Gradle, инструменты генерации или
разработческие тестовые моды. Состав и совместимость конкретной сборки зависят
также от требований остальных установленных модов; проверенные запуски указаны
в [отчёте 0.2.0](VALIDATION_0.2.0.md).

Файл `*-sources.jar` содержит исходники; для игры выбирайте обычный
`realistic-home-decor-0.2.0.jar`. Полный архив проекта также не помещают в `mods`.

Для выделенного сервера установите этот же JAR и Fabric API в серверную папку
`mods`. Подключающимся игрокам тоже нужны мод и Fabric API.

## Где получить файл

Готовая копия находится прямо в корне репозитория:
[realistic-home-decor-0.2.0.jar](../realistic-home-decor-0.2.0.jar).
На GitHub откройте файл и нажмите **Download raw file**. Если скачиваете весь
репозиторий через **Code → Download ZIP**, этот JAR будет внутри архива.
Файл не исключён через `.gitignore`.

После успешной сборки готовая пара файлов находится в:

```text
build/distributions/release/
  realistic-home-decor-0.2.0.jar
  SHA256SUMS
```

Задача `packageRelease` автоматически обновляет идентичную копию JAR в корне.
Контрольная сумма относится к обеим копиям одного файла.

В GitHub откройте **Actions → Build installable Fabric mod → успешный запуск →
Artifacts → realistic-home-decor-minecraft-1.21.11**. Распакуйте скачанный архив
артефакта и возьмите из него JAR. Сборка публикует только устанавливаемый мод и
его контрольную сумму, без разработческих JAR. Доступность артефакта зависит от
того, был ли соответствующий commit отправлен в GitHub и завершился ли CI.

Чтобы собрать самостоятельно, из корня проекта с JDK 21 и Python 3.10+ выполните:

```bash
./gradlew --no-daemon build
```

В Windows используется `gradlew.bat`. Команда `packageRelease` проверяет
метаданные и отсутствие тестовых классов перед упаковкой устанавливаемого файла.

## Обновление существующего мира

Все 320 ID предметов версии 0.1.0 сохранены. Новые палитры и стены добавляются
отдельными ID. Керамика и бетон некоторых старых палитр получили согласованные
оттенки; это намеренное изменение внешнего вида, описанное в [PALETTES.md](PALETTES.md).
Перед обычным обновлением сборки сохраните копию своего мира.
