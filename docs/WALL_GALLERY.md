# Галерея стен 0.2.0

Генератор создаёт отдельный datapack Minecraft 1.21.11, формат 94.1: **40 новых конструкций стен**, по **8 палитр**. Новые стены определяются полем `wall_family` каталога; старые настенные часы, бра, полки, панели и раковины не учитываются как новые конструкции.

```bash
python3 tools/wall_gallery.py
python3 tools/wall_gallery.py --check
python3 -m unittest tests.test_wall_gallery -v
```

По умолчанию файлы появляются в `build/wall-gallery`. Python не ищет сохранения, не запускает игру и не ставит блоки. Повторная генерация проверяется `--check`; неизвестная непустая папка, посторонние файлы и небезопасные пути отклоняются.

Галерея — сетка **8 столбцов × 5 рядов**. В каждой ячейке находится цельный участок стены **3×3 блока** в палитре `oak`, над ним — восемь одноблочных образцов в два ряда по четыре. Нижний ряд палитр слева направо: `oak`, `walnut`, `ebony`, `ivory`; верхний: `sand`, `slate`, `terracotta`, `sage`. Между большим участком и образцами оставлен воздушный промежуток. Всего **680 демонстрационных блоков**, включая повторное использование `oak` в палитровой полосе.

Стены смотрят на север. Координаты, семейства, названия, ID и порядок ячеек записаны в `gallery_manifest.json`; для позиции мира нужно прибавить выбранное начало. Описание конструкций и материалов — в [WALLS.md](WALLS.md) и [PALETTES.md](PALETTES.md).

## Установка в тестовый мир

**Только отдельный тестовый мир с резервной копией.** `build` и `clear` изменяют весь объём относительно начала: **[0,−1,0]…[63,6,47]**, включая пол. Объём очистки — 24 576 блоков, меньше стандартного лимита `fill` 32 768. Для начала `(0,81,0)` это мировые координаты `(0,80,0)…(63,87,47)`.

Создать и закрыть отдельный мир, затем скопировать содержимое `build/wall-gallery` в его `datapacks/rhd_walls`. Можно явно направить генератор в пустую папку datapack этого мира:

```bash
python3 tools/wall_gallery.py --output /путь/к/тестовому/миру/datapacks/rhd_walls
```

После загрузки мира выполнить команды с правами оператора. Начало должно оставаться одинаковым во всех командах:

```mcfunction
/reload
/execute positioned 0 81 0 run function rhd_walls:prepare
```

Подождать не менее пяти секунд, затем:

```mcfunction
/execute positioned 0 81 0 run function rhd_walls:build
```

В журнале должно появиться `RHD_WALL_GALLERY_BUILT templates=40 palettes=8 display_blocks=680`. Если сообщения нет, чанки ещё не загружены: подождать и повторить. Обёртка проверяет загрузку всех чанков до изменения мира.

Через секунду проверить все блоки и направления:

```mcfunction
/execute positioned 0 81 0 run function rhd_walls:verify
```

`RHD_WALL_GALLERY_MISSING` означает отказ. Сообщение `VERIFIED` само по себе не означает успех, если перед ним были `MISSING`. Проверка пишет в серверный журнал даже без подключённых игроков. Повторить после сохранения и перезапуска мира.

Для постоянного дневного освещения в этом тестовом мире можно явно выполнить команды Minecraft 1.21.11:

```mcfunction
/gamerule minecraft:advance_time false
/gamerule minecraft:advance_weather false
/time set 6000
/weather clear 1000000
```

Для удаления всей галереи, **включая пол**, и снятия принудительной загрузки:

```mcfunction
/execute positioned 0 81 0 run function rhd_walls:clear
/execute positioned 0 81 0 run function rhd_walls:release
```

`release` также снимает ранее включённую принудительную загрузку внутри этого региона. Datapack не содержит сущностей, tick-функций и автоматических load-функций; само подключение datapack мир не перестраивает. Проверка через команды не заменяет визуальный осмотр, размещение предметом игрока и испытания разрушения/выпадения.
