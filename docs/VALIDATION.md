# Фактически выполненные проверки

Дата: **25 октября 2026 года**. Minecraft **1.21.11**, Fabric Loader **0.20.1**,
Fabric API **0.141.6+1.21.11**, Temurin JDK **21.0.13+9**, Gradle **9.2.1**,
Loom **1.14.10**. Проверки выполнялись в настоящих Minecraft-процессах облачной
среды, а не только на схемах JSON.

ожидаемые повороты, сохранение объёма, границы и некорректные входные значения.

## Настоящий серверный тест

Отдельный разработческий мод `rhd_smoke_test` запускался в выделенном сервере
на отдельном временном мире. Итоговый маркер:

```text
RHD_SMOKE_PASS assertions=3921 placements=345 catalog=320
```

Маркер ошибки отсутствовал; сервер корректно сохранил мир и завершил работу.
Проверены:

- Реальные вызовы `FurnitureBlockItem.place` для всех 320 предметов через
  стандартный `DirectionalPlaceContext`, расход стека, ID и положения всех частей.
- Четыре направления многоблочных, настенных и потолочных конструкций.
- Независимое сравнение повёрнутых voxel shapes, соединение секций во всех
  направлениях, соответствующие состояния и коллизии после удаления соседа.
- Отказ размещения при занятой вторичной ячейке без частичной установки и
  расходования предмета; проверка опор.
- Отложенная очистка после потери опоры и разрушения вторичной части, ровно один
  основной предмет в проверке выпадения, очистка на границе чанков.

Это программные действия в настоящем мире сервера. Они не заменяют полный
ручной проход игроком всех вариантов мебели. `./gradlew build` компилирует
серверный тестовый мод, но не запускает Minecraft-сервер автоматически.

Для повторения используйте `./gradlew runSmokeServer` после принятия EULA в
`run/smoke-server/eula.txt`. В текущей подготовленной среде тестовый сервер
настроен на loopback-порт 25566. Проверяйте **свежий** `RHD_SMOKE_PASS` и отсутствие
`RHD_SMOKE_FAIL`: сам Minecraft может вернуть код 0 после остановки неудачного
тестового прогона. Обычный сервер и релизный JAR этот тестовый мод не загружают.

## Сцены и сохранение мира

Production JAR отдельно проверен **обычным Fabric launcher**, установленным
официальным Fabric Installer **1.1.2**, без Gradle, development classpath и
тестовых модов. Установлены только релизный JAR и Fabric API. Зарегистрированы
320 предметов / 540 блоков / 11 вкладок. Нативная сцена на 1000 предметов
охватила все 320 ID; все 1702 части присутствовали до и после сохранения,
остановки и перезапуска. Отдельно проверена очистка обеих ячеек дивана при
разрушении первичной и вторичной частей. Все проверки прошли.

Обычный выделенный сервер без тестового мода загрузил текущий datapack 94.1.
После установки и ожидания отложенной проверки получены результаты:

| Целых предметов | Мебельных блоков | Неожиданно отсутствующие части |
|---:|---:|---:|
| 100 | 174 | 0 |
| 500 | 852 | 0 |
| 1000 | 1702 | 0 |

Контрольная поломка: намеренно удалена первичная часть `computer_desk_walnut`.
Проверка обнаружила ровно две ожидаемые отсутствующие части. После
восстановления сцены повторная проверка прошла.

Затем выполнены `save-all flush`, корректная остановка и повторный запуск.
Все **1702 части** сцены на 1000 предметов сохранились; повторный `verify_1000`
не обнаружил пропусков. Клиент с модом успешно подключался к серверу.

## Клиент и визуальные проверки

Настоящий клиент Minecraft запущен через Xvfb и программный OpenGL. Мод
зарегистрировал каталог; Minecraft загрузил ресурсы и атласы. Ошибок загрузки
моделей и текстур мода в журнале не обнаружено.

Ручные снимки подтверждают видимые детали стула, обеденного стола, дивана,
кухонного шкафа, унитаза и стеклянной душевой. В этих ракурсах нет отсутствующих
текстур; прозрачность стекла работает. Открыты вкладки и иконки предметов;
в игре переключён язык и проверены английские и русские названия.

Это выборочный осмотр, а не заявление о полном ручном осмотре всех 320 вариантов
со всех сторон. Снимки экрана получены непосредственно из игры, без ретуши:

- [Галерея 1000 предметов](screenshots/catalog-in-game.png)
- [Диван](screenshots/sofa-in-game.png)
- [Прозрачная душевая](screenshots/shower-in-game.png)
- [Русский каталог и название предмета](screenshots/creative-ru.png)
- [Английский каталог](screenshots/creative-en.png)

Необязательные запросы Realms, профиля и ключей Microsoft в этой ограниченной
облачной среде могут завершаться сетевыми ошибками. Для проверок использовался
изолированный сервер на loopback с `online-mode=false`. Онлайн-аутентификация
Microsoft не проверялась. Физическое воспроизведение звука не проверялось:
для графического клиента использован null-backend OpenAL.

Методика производительности и фактические диагностические замеры облачной
среды приведены отдельно в [PERFORMANCE.md](PERFORMANCE.md). Они не являются
замерами на игровой видеокарте; совместимость со сторонними шейдерами и модами
оптимизации требует отдельной серии.
